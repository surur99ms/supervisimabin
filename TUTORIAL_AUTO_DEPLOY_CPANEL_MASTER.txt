- Provider hosting sering MEMATIKAN fungsi PHP 'shell_exec()' sehingga file

   pengaturan awal di dashboard cPanel (10%).

[OPSI A]: SKRIP TUNGGAL 'autodeploy.sh' (Untuk 1 Proyek Saja)
................................................................................
Buat file baru 'autodeploy.sh', klik Edit, dan salin kode ini:

#!/bin/bash
export PATH=/usr/local/bin:/usr/bin:/bin:$PATH

# --- KONFIGURASI PATH SERVER ---
REPO=/home/jsnimmnm/repositories/tokonesia
DOC=/home/jsnimmnm/tokonesia.corefive.my.id
LOGDIR=/home/jsnimmnm/logs
LOG="$LOGDIR/autodeploy.log"

mkdir -p "$LOGDIR"
log(){ echo "$(date '+%F %T') $*" >> "$LOG"; }

# 1. Kunci proses (mencegah bentrok jika cron jalan bersamaan)
LOCK="$LOGDIR/.autodeploy.lock"
find "$LOCK" -maxdepth 0 -mmin +3 -exec rm -rf {} + 2>/dev/null
mkdir "$LOCK" 2>/dev/null || { log "SKIP: proses sebelumnya masih berjalan"; exit 0; }
trap 'rm -rf "$LOCK"' EXIT INT TERM

# 2. Validasi direktori
command -v git >/dev/null 2>&1 || { log "ERROR: git tidak ditemukan di server"; exit 1; }
[ -d "$REPO/.git" ] || { log "ERROR: repo tidak ditemukan di $REPO"; exit 1; }
[ -d "$DOC" ]       || { log "ERROR: docroot tidak ditemukan di $DOC"; exit 1; }

cd "$REPO" || { log "ERROR: gagal masuk ke direktori $REPO"; exit 1; }

# 3. Ambil commit terbaru dari GitHub
if ! OUT=$(git fetch origin 2>&1); then
  log "ERROR: git fetch gagal -> $OUT"; exit 1
fi

LOCAL=$(git rev-parse HEAD 2>/dev/null)
REMOTE=$(git rev-parse origin/main 2>/dev/null)
[ -z "$REMOTE" ] && { log "ERROR: gagal membaca branch origin/main"; exit 1; }

# Jika tidak ada update commit baru, berhenti diam-diam (hemat CPU hosting)
[ "$LOCAL" = "$REMOTE" ] && exit 0

log "MULAI deploy pembaruan: ${LOCAL:0:7} -> ${REMOTE:0:7}"

# 4. Sinkronkan git server ke commit terbaru
if ! OUT=$(git reset --hard "$REMOTE" 2>&1); then
  log "ERROR: git reset gagal -> $OUT"; exit 1
fi

# 5. Salin perubahan file ke folder domain publik (proteksi database & aset aman)
if ! OUT=$( { tar -cf - --exclude='.git' --exclude='.github' --exclude='.cpanel.yml' \
              --exclude='.gitignore' --exclude='.gitattributes' \
              --exclude='autodeploy.sh' \
              --exclude='config.php' \
              --exclude='koneksi.php' \
              --exclude='mobile_app' \
              --exclude='uploads' \
              --exclude='*.sql' . \
  | ( cd "$DOC" && tar -xf - --no-overwrite-dir --no-same-permissions ); } 2>&1 ); then
  log "ERROR: penyalinan file gagal -> $OUT"; exit 1
fi

# 6. Kunci izin direktori aman
chmod 750 "$DOC" 2>/dev/null
rm -rf "$LOCK"
log "SUKSES: deploy commit ${REMOTE:0:7} selesai sempurna!"

[OPSI B]: MASTER SCRIPT 'master_deploy.sh' (BISA UNTUK 30+ PROYEK SEKALIGUS!)
>>> INI YANG SANGAT DIREKOMENDASIKAN KARENA SUDAH ADA MASTER DEPLOYER! <<<
................................................................................
Buat file baru 'master_deploy.sh', klik Edit, dan salin kode ini:

#!/bin/bash
export PATH=/usr/local/bin:/usr/bin:/bin:$PATH

# ==============================================================================
# DAFTAR SEMUA WEBSITE ANDA (BISA DITAMBAH HINGGA 30+ PROYEK)
# Format: "NAMA_REPO_GIT:NAMA_FOLDER_DOMAIN"
# ==============================================================================
PROYEK_LIST=(
    "supervisimabin:supervisi.mabin.corefive.my.id"
    "tokonesia:tokonesia.corefive.my.id"
    # Jika besok ada proyek ke-3, ke-4, dst, cukup tambahkan 1 baris di bawah ini:
    # "nama_repo_baru:folder_domain_baru.com"
)

HOME_DIR="/home/jsnimmnm"
LOGDIR="$HOME_DIR/logs"
LOG="$LOGDIR/master_deploy.log"

mkdir -p "$LOGDIR"
log(){ echo "$(date '+%F %T') [$1] $2" >> "$LOG"; }

# Gembok Master Anti-Bentrok
MASTER_LOCK="$LOGDIR/.master_deploy.lock"
find "$MASTER_LOCK" -maxdepth 0 -mmin +5 -exec rm -rf {} + 2>/dev/null
mkdir "$MASTER_LOCK" 2>/dev/null || exit 0
trap 'rm -rf "$MASTER_LOCK"' EXIT INT TERM

command -v git >/dev/null 2>&1 || { echo "$(date '+%F %T') [SYSTEM] ERROR: git tidak ditemukan di server" >> "$LOG"; exit 1; }

# Loop seluruh website satu per satu
for ITEM in "${PROYEK_LIST[@]}"; do
    [[ "$ITEM" =~ ^#.* ]] && continue
    [ -z "$ITEM" ] && continue

    REPO_NAME="${ITEM%%:*}"
    DOC_NAME="${ITEM##*:}"

    REPO="$HOME_DIR/repositories/$REPO_NAME"
    DOC="$HOME_DIR/$DOC_NAME"

    [ -d "$REPO/.git" ] || continue
    [ -d "$DOC" ] || continue

    cd "$REPO" || continue
    git fetch -q origin 2>/dev/null || continue

    LOCAL=$(git rev-parse HEAD 2>/dev/null)
    REMOTE=$(git rev-parse origin/main 2>/dev/null)

    [ -z "$REMOTE" ] && continue
    [ "$LOCAL" = "$REMOTE" ] && continue

    log "$REPO_NAME" "MULAI deploy: ${LOCAL:0:7} -> ${REMOTE:0:7}"

    if ! OUT=$(git reset -q --hard "$REMOTE" 2>&1); then
        log "$REPO_NAME" "ERROR: git reset gagal -> $OUT"
        continue
    fi

    # Salin file ke folder domain web publik (Proteksi database & aset aman)
    if ! OUT=$( { tar -cf - \
                  --exclude='.git' \
                  --exclude='.github' \
                  --exclude='.cpanel.yml' \
                  --exclude='.gitignore' \
                  --exclude='.gitattributes' \
                  --exclude='autodeploy*.sh' \
                  --exclude='master_deploy.sh' \
                  --exclude='config.php' \
                  --exclude='koneksi.php' \
                  --exclude='database.php' \
                  --exclude='mobile_app' \
                  --exclude='uploads' \
                  --exclude='media' \
                  --exclude='*.sql' . \
      | ( cd "$DOC" && tar -xf - --no-overwrite-dir --no-same-permissions ); } 2>&1 ); then
        log "$REPO_NAME" "ERROR: penyalinan file gagal -> $OUT"
        continue
    fi

    if [ -f "$DOC/migrate.php" ]; then
        php "$DOC/migrate.php" >> "$LOG" 2>&1
    fi

    chmod 750 "$DOC" 2>/dev/null
    log "$REPO_NAME" "SUKSES: deploy commit ${REMOTE:0:7} selesai sempurna!"
done

rm -rf "$MASTER_LOCK"

7. TROUBLESHOOTING: CARA CEK JIKA KODE BELUM MUNCUL DI WEBSITE
================================================================================
Jika setelah push ke GitHub website belum berubah, buka File Manager cPanel dan
cek file log berikut:

1. File: /home/jsnimmnm/logs/master_deploy-run.log (atau autodeploy-run.log)
   Fungsi: Memastikan Cron Job cPanel benar-benar memanggil skrip bash.
   Jika file ini ada dan tidak ada pesan error merah, berarti cron job aktif.

2. File: /home/jsnimmnm/logs/master_deploy.log (atau autodeploy.log)
   Fungsi: Melihat riwayat deploy. Anda akan melihat baris seperti ini:
   "2026-11-18 01:00:02 [supervisimabin] MULAI deploy: 9e083d1 -> da93a08"
   "2026-11-18 01:00:03 [supervisimabin] SUKSES: deploy commit da93a08 selesai sempurna!"

3. Masalah Browser Cache di HP/Laptop:
   Seringkali website di server SEBENARNYA SUDAH BERUBAH, tapi browser menampilkan cache lama.
   Tekan 'Ctrl + F5' di laptop, atau buka lewat mode 'Incognito / Tab Samaran' di HP.
