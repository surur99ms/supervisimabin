Dengan Sistem Master Deployer:

2. FASE 1: SETUP AWAL DI CPANEL (CUKUP 1 KALI SAJA SEUMUR HIDUP!)
================================================================================
Langkah ini hanya Anda lakukan SEKALI SAJA saat pertama kali.

--------------------------------------------------------------------------------
LANGKAH 1: MEMBUAT FILE 'master_deploy.sh' DI FOLDER 'bin/'
--------------------------------------------------------------------------------
1. Buka File Manager di cPanel.
2. Masuk ke folder 'bin/' (/home/jsnimmnm/bin/).
   *(Jika folder 'bin' belum ada, klik "+ Folder" dan beri nama 'bin')*.
3. Klik tombol "+ File" di pojok kiri atas -> beri nama: 'master_deploy.sh'.
4. Klik kanan file 'master_deploy.sh' -> pilih "Edit".
5. Salin SELURUH KODE di BAGIAN 3 ke dalam file tersebut.
6. Klik "Save Changes".
7. Klik kanan file 'master_deploy.sh' -> pilih "Change Permissions" -> centang Execute (755).

--------------------------------------------------------------------------------
LANGKAH 2: MEMASANG 1 BARIS CRON JOB DI CPANEL
--------------------------------------------------------------------------------
1. Buka menu "Cron Jobs" di cPanel.
2. Hapus baris-baris cron job lama Anda (agar bersih dan tidak bentrok).
3. Pada Common Settings: Pilih "Once Every 5 Minutes (*/5 * * * *)".
4. Pada kolom Command, masukkan 1 baris sakti ini:

sed -i 's/\r$//' /home/jsnimmnm/bin/master_deploy.sh; /bin/bash /home/jsnimmnm/bin/master_deploy.sh >> /home/jsnimmnm/logs/master_deploy-run.log 2>&1

5. Klik tombol "Add New Cron Job". SELESAI SETUP AWAL!

3. KODE MASTER SCRIPT 'master_deploy.sh' (STANDAR EMAS)
================================================================================
Salin seluruh kode di bawah ini ke file '/home/jsnimmnm/bin/master_deploy.sh':

------------------- [MULAI SALIN KODE DI BAWAH INI] -------------------
#!/bin/bash
export PATH=/usr/local/bin:/usr/bin:/bin:$PATH

# ==============================================================================
# DAFTAR SEMUA WEBSITE ANDA (BISA DITAMBAH HINGGA 30+ PROYEK)
# Format: "NAMA_REPO_GIT:NAMA_FOLDER_DOMAIN"
# ==============================================================================
PROYEK_LIST=(
    "supervisimabin:supervisi.mabin.corefive.my.id"
    "tokonesia:tokonesia.corefive.my.id"
    # Jika ada proyek ke-3, ke-4, dst, cukup tambahkan di bawah ini:
    # "nama_repo_baru:folder_domain_baru.com"
)

# Direktori Dasar cPanel
HOME_DIR="/home/jsnimmnm"
LOGDIR="$HOME_DIR/logs"
LOG="$LOGDIR/master_deploy.log"

mkdir -p "$LOGDIR"
log(){ echo "$(date '+%F %T') [$1] $2" >> "$LOG"; }

# Gembok Master Anti-Bentrok
MASTER_LOCK="$LOGDIR/.master_deploy.lock"
find "$MASTER_LOCK" -maxdepth 0 -mmin +5 -exec rm -rf {} + 2>/dev/null
mkdir "$MASTER_LOCK" 2>/dev/null || exit 0
trap 'rm -rf "$MASTER_LOCK"' EXIT INT TERM

# Validasi perintah git
command -v git >/dev/null 2>&1 || { echo "$(date '+%F %T') [SYSTEM] ERROR: git tidak ditemukan di server" >> "$LOG"; exit 1; }

# ==============================================================================
# PROSES OTOMATIS: PERIKSA SETIAP WEBSITE SATU PER SATU
# ==============================================================================
for ITEM in "${PROYEK_LIST[@]}"; do
    # Lewati baris komentar (#) atau baris kosong
    [[ "$ITEM" =~ ^#.* ]] && continue
    [ -z "$ITEM" ] && continue

    REPO_NAME="${ITEM%%:*}"
    DOC_NAME="${ITEM##*:}"

    REPO="$HOME_DIR/repositories/$REPO_NAME"
    DOC="$HOME_DIR/$DOC_NAME"

    # Pastikan repo git dan folder domain benar-benar ada di server
    [ -d "$REPO/.git" ] || continue
    [ -d "$DOC" ] || continue

    cd "$REPO" || continue

    # Tarik status commit terbaru dari GitHub
    git fetch -q origin 2>/dev/null || continue

    LOCAL=$(git rev-parse HEAD 2>/dev/null)
    REMOTE=$(git rev-parse origin/main 2>/dev/null)

    # Jika tidak ada commit baru, lewati (hemat CPU hosting)
    [ -z "$REMOTE" ] && continue
    [ "$LOCAL" = "$REMOTE" ] && continue

    log "$REPO_NAME" "MULAI deploy: ${LOCAL:0:7} -> ${REMOTE:0:7}"

    # Sinkronkan repo server ke commit terbaru
    if ! OUT=$(git reset -q --hard "$REMOTE" 2>&1); then
        log "$REPO_NAME" "ERROR: git reset gagal -> $OUT"
        continue
    fi

    # Salin file ke folder domain (Proteksi database, app mobile, sql & uploads aman)
    if ! OUT=$( { tar -cf - \
                  --exclude='.git' \
                  --exclude='.github' \
                  --exclude='.cpanel.yml' \
                  --exclude='.gitignore' \
                  --exclude='.gitattributes' \
                  --exclude='autodeploy*.sh' \
                  --exclude='master_deploy.sh' \
                  --exclude='config.php' \
                  --exclude='koneksi.php' \
                  --exclude='database.php' \
                  --exclude='mobile_app' \
                  --exclude='uploads' \
                  --exclude='media' \
                  --exclude='*.sql' . \
      | ( cd "$DOC" && tar -xf - --no-overwrite-dir --no-same-permissions ); } 2>&1 ); then
        log "$REPO_NAME" "ERROR: penyalinan file gagal -> $OUT"
        continue
    fi

    # Eksekusi migrasi database otomatis jika ada file migrate.php
    if [ -f "$DOC/migrate.php" ]; then
        php "$DOC/migrate.php" >> "$LOG" 2>&1
    fi

    chmod 750 "$DOC" 2>/dev/null
    log "$REPO_NAME" "SUKSES: deploy commit ${REMOTE:0:7} selesai sempurna!"
done

rm -rf "$MASTER_LOCK"
------------------- [BATAS AKHIR SALIN KODE] -------------------

4. FASE 2: CARA MENAMBAH PROYEK BARU SETERUSNYA (CUMA 1 MENIT!)
================================================================================
Setelah Fase 1 selesai, jika besok Bos Surur membuat website baru (misal: 'koperasi'):

❌ TIDAK PERLU membuat folder bin baru.
❌ TIDAK PERLU membuat file script deploy baru.
❌ TIDAK PERLU menambah baris Cron Job baru di cPanel.

CUKUP LAKUKAN 2 LANGKAH RINGKAS INI:

Langkah 1: Kloning di cPanel Git Version Control
1. Di cPanel, buka menu "Git™ Version Control" -> klik "+ Create".
2. Isi formulir:
   - Clone URL       : Masukkan link GitHub proyek baru Anda
   - Repository Path : repositories/koperasi
3. Klik "Create". (Pastikan statusnya Success).

Langkah 2: Daftarkan ke 'master_deploy.sh'
1. Buka File Manager cPanel -> buka file '/home/jsnimmnm/bin/master_deploy.sh' -> Edit.
2. Tambahkan 1 baris nama proyek baru di dalam daftar 'PROYEK_LIST':
   ```bash
   PROYEK_LIST=(
       "supervisimabin:supervisi.mabin.corefive.my.id"
       "tokonesia:tokonesia.corefive.my.id"
       "koperasi:koperasi.corefive.my.id"      <-- CUKUP TAMBAH BARIS INI!
   )
   ```
3. Klik "Save Changes".

SELESAI! Website baru tersebut langsung otomatis ter-deploy setiap 5 menit bersama
website-website lainnya tanpa perlu mengatur apa pun lagi!

5. FASE 3: ALUR KERJA HARIAN SETERUSNYA (100% OTOMATIS)
================================================================================
Alur kerja harian Bos Surur bersama AI Agent:
1. Bos Surur meminta perubahan pada AI di laptop:
   "Tolong ubah warna header dan update fitur laporan."
2. AI Agent mengedit kode, mengetes di Laragon, lalu menjalankan:
   git add .
   git commit -m "Update fitur laporan"
   git push origin main
3. Dalam hitungan 1-5 menit:
   Server cPanel otomatis mendeteksi ada commit baru -> menarik kode baru
   -> website di hosting otomatis ter-update secara live!
4. Bos Surur cukup refresh browser di HP atau laptop untuk melihat hasilnya.

6. TROUBLESHOOTING & CARA MEMERIKSA LOG
================================================================================
Jika ada website yang belum berubah setelah 5 menit:

1. Periksa Log Riwayat Deployment:
   Buka file ini di File Manager cPanel:
   👉 /home/jsnimmnm/logs/master_deploy.log

   Catatan deploy akan tampil sangat rapi per website:
   2026-11-18 01:00:02 [supervisimabin] MULAI deploy: 9e083d1 -> da93a08
   2026-11-18 01:00:03 [supervisimabin] SUKSES: deploy commit da93a08 selesai sempurna!

2. Masalah Browser Cache di HP/Laptop:
   Seringkali file di server SEBENARNYA SUDAH BERUBAH, tapi browser menampilkan cache lama.
   Tekan tombol 'Ctrl + F5' di laptop, atau buka website lewat mode 'Incognito / Tab Samaran' di HP.
