1. KONSEP INTI MASTER DEPLOYER (MENGAPA JAUH LEBIH CEPAT & RAPI?)
================================================================================
Jika Bos Surur punya 5, 10, sampai 30 website di satu akun cPanel:
❌ Jangan membuat folder 'bin01', 'bin02', 'bin03' ... sampai 30 folder.
❌ Jangan memasang 30 baris Cron Job di cPanel (server berat dan gembok lock bentrok).

✅ CUKUP GUNAKAN SISTEM MASTER DEPLOYER:
- Folder script cukup 1 saja: /home/jsnimmnm/bin/
- Script cukup 1 file saja   : /home/jsnimmnm/bin/master_deploy.sh
- Cron Job di cPanel         : CUKUP 1 BARIS SAJA selamanya!
- Setiap 5 menit, script master akan memeriksa seluruh daftar website Anda:
  * Website yang ADA commit update di GitHub -> Otomatis di-deploy ke web publik.
  * Website yang TIDAK ADA update           -> Dilewati (skip) dalam 0.05 detik (hemat CPU).

3. CARA SETUP AWAL DI CPANEL (HANYA DILAKUKAN 1 KALI SEUMUR HIDUP)
================================================================================

LANGKAH 1: MEMBUAT FILE 'master_deploy.sh'
1. Buka cPanel -> klik "File Manager".
2. Masuk ke folder 'bin/' (/home/jsnimmnm/bin/).
   *(Jika folder 'bin' belum ada, klik "+ Folder" dan beri nama 'bin')*.
3. Klik tombol "+ File" di pojok kiri atas -> beri nama: 'master_deploy.sh'.
4. Klik kanan file 'master_deploy.sh' -> pilih "Edit".
5. Salin seluruh isi kode pada BAGIAN 4 di bawah ini, lalu klik "Save Changes".
6. Klik kanan file 'master_deploy.sh' -> pilih "Change Permissions" -> ubah ke 755.

LANGKAH 2: MEMASANG 1 BARIS CRON JOB SAKTI
1. Buka cPanel -> klik menu "Cron Jobs".
2. Pada Common Settings: Pilih "Once Every 5 Minutes (*/5 * * * *)".
3. Pada kolom Command, masukkan 1 baris sakti ini:

sed -i 's/\r$//' /home/jsnimmnm/bin/master_deploy.sh; /bin/bash /home/jsnimmnm/bin/master_deploy.sh >> /home/jsnimmnm/logs/master_deploy-run.log 2>&1

4. Klik tombol "Add New Cron Job" (atau simpan hasil edit dari Baris 1 tadi).

4. KODE LENGKAP 'master_deploy.sh' (SIAP SALIN & TEMPEL)
================================================================================
------------------- [MULAI SALIN KODE DI BAWAH INI] -------------------
#!/bin/bash
export PATH=/usr/local/bin:/usr/bin:/bin:$PATH

# ==============================================================================
# DAFTAR SEMUA WEBSITE ANDA (BISA DITAMBAH HINGGA 30+ PROYEK)
# Format pengisian: "NAMA_REPO_GIT:NAMA_FOLDER_DOMAIN_WEB"
# ==============================================================================
PROYEK_LIST=(
    "supervisimabin:supervisi.mabin.corefive.my.id"
    "tokonesia:tokonesia.corefive.my.id"
    # Jika besok ada proyek ke-3, ke-4, dst, cukup tambahkan di bawah ini:
    # "nama_repo_baru:folder_domain_baru.com"
)

# Direktori Dasar cPanel
HOME_DIR="/home/jsnimmnm"
LOGDIR="$HOME_DIR/logs"
LOG="$LOGDIR/master_deploy.log"

mkdir -p "$LOGDIR"
log(){ echo "$(date '+%F %T') [$1] $2" >> "$LOG"; }

# Gembok Master (Mencegah dua eksekusi cron bertabrakan)
MASTER_LOCK="$LOGDIR/.master_deploy.lock"
find "$MASTER_LOCK" -maxdepth 0 -mmin +5 -exec rm -rf {} + 2>/dev/null
mkdir "$MASTER_LOCK" 2>/dev/null || exit 0
trap 'rm -rf "$MASTER_LOCK"' EXIT INT TERM

# Validasi perintah git
command -v git >/dev/null 2>&1 || { echo "$(date '+%F %T') [SYSTEM] ERROR: git tidak ditemukan di server" >> "$LOG"; exit 1; }

# ==============================================================================
# PROSES OTOMATIS: PERIKSA SETIAP WEBSITE SATU PER SATU
# ==============================================================================
for ITEM in "${PROYEK_LIST[@]}"; do
    # Lewati baris komentar (#) atau baris kosong
    [[ "$ITEM" =~ ^#.* ]] && continue
    [ -z "$ITEM" ] && continue

    REPO_NAME="${ITEM%%:*}"
    DOC_NAME="${ITEM##*:}"

    REPO="$HOME_DIR/repositories/$REPO_NAME"
    DOC="$HOME_DIR/$DOC_NAME"

    # Pastikan repo git dan folder domain benar-benar ada di server
    [ -d "$REPO/.git" ] || continue
    [ -d "$DOC" ] || continue

    cd "$REPO" || continue

    # Tarik status commit terbaru dari GitHub
    git fetch -q origin 2>/dev/null || continue

    LOCAL=$(git rev-parse HEAD 2>/dev/null)
    REMOTE=$(git rev-parse origin/main 2>/dev/null)

    # Jika origin/main tidak terbaca atau tidak ada commit baru, lewati (hemat CPU hosting)
    [ -z "$REMOTE" ] && continue
    [ "$LOCAL" = "$REMOTE" ] && continue

    log "$REPO_NAME" "MULAI deploy: ${LOCAL:0:7} -> ${REMOTE:0:7}"

    # Sinkronkan repo server ke commit terbaru
    if ! OUT=$(git reset -q --hard "$REMOTE" 2>&1); then
        log "$REPO_NAME" "ERROR: git reset gagal -> $OUT"
        continue
    fi

    # Salin file ke folder domain web publik (Proteksi database, app mobile & sql aman)
    if ! OUT=$( { tar -cf - \
                  --exclude='.git' \
                  --exclude='.github' \
                  --exclude='.cpanel.yml' \
                  --exclude='.gitignore' \
                  --exclude='.gitattributes' \
                  --exclude='autodeploy*.sh' \
                  --exclude='master_deploy.sh' \
                  --exclude='config.php' \
                  --exclude='koneksi.php' \
                  --exclude='database.php' \
                  --exclude='mobile_app' \
                  --exclude='uploads' \
                  --exclude='media' \
                  --exclude='*.sql' . \
      | ( cd "$DOC" && tar -xf - --no-overwrite-dir --no-same-permissions ); } 2>&1 ); then
        log "$REPO_NAME" "ERROR: penyalinan file gagal -> $OUT"
        continue
    fi

    # Eksekusi migrasi database otomatis jika ada file migrate.php
    if [ -f "$DOC/migrate.php" ]; then
        php "$DOC/migrate.php" >> "$LOG" 2>&1
    fi

    chmod 750 "$DOC" 2>/dev/null
    log "$REPO_NAME" "SUKSES: deploy commit ${REMOTE:0:7} selesai sempurna!"
done

rm -rf "$MASTER_LOCK"
------------------- [BATAS AKHIR SALIN KODE] -------------------

5. CARA MENAMBAH PROYEK BARU SETERUSNYA (HANYA BUTUH 1 MENIT!)
================================================================================
Jika nanti Bos Surur membuat website baru (misal: proyek 'koperasi'):

Bos Surur TIDAK PERLU membuat folder bin baru ataupun membuat cron job baru!
Cukup lakukan 2 langkah super cepat ini:

Langkah 1: Clone di cPanel Git Version Control
- Di cPanel, buka menu "Git™ Version Control" -> klik "+ Create".
- Clone URL       : Masukkan link GitHub proyek baru Anda
- Repository Path : repositories/koperasi
- Klik "Create".

Langkah 2: Daftarkan ke 'master_deploy.sh'
- Buka File Manager cPanel -> buka file '/home/jsnimmnm/bin/master_deploy.sh' -> pilih Edit.
- Tambahkan 1 baris nama proyek baru di dalam daftar 'PROYEK_LIST':
  ```bash
  PROYEK_LIST=(
      "supervisimabin:supervisi.mabin.corefive.my.id"
      "tokonesia:tokonesia.corefive.my.id"
      "koperasi:koperasi.corefive.my.id"      <-- CUKUP TAMBAH BARIS INI!
  )
  ```
- Klik "Save Changes".

SELESAI! Website baru tersebut langsung otomatis ter-autodeploy setiap 5 menit bersama
website-website lainnya tanpa perlu menyentuh menu Cron Jobs lagi selamanya!
